## SCR-01. Скрипты жизненного цикла — ВЫПОЛНЕНО (переработано 2026-10-02)

- `client/entrypoint.sh`: первый аргумент — имя бинарника 1С
  (`1cv8c`/`1cv8`/`1cestart`), остальное — ключи; неизвестное слово =
  первый аргумент `1cv8`; `LC_ALL=ru_RU.UTF-8`,
  `GTK_USE_PORTAL=1`; PID-1 ветка: trap SIGTERM, цикл `pgrep 1cv8` +
  `read -t 2`, `wait -n` реапит зомби;
- `bin/1c-run.sh`: команды start/stop/status/build/build+start/help;
  вариантные сборки build+test / build+breeze (тег один — последний
  собранный); exec при живом контейнере, run с `--rm` при отсутствии;
  session-dbus хоста монтируется; build+breeze включает тему в
  `volumes/home/.config/gtk-3.0/settings.ini`, обычный build снимает;
- тома: home (единый персистентный, с профилем клиента), techjournal
  (`/tmp/1c-techjournal`), licenses, logconf (logcfg.xml
  файлом при наличии); exchange и client-profile удалены.

Проверено: холодный старт, файловая база (конфигуратор, толстый,
тонкий, русский интерфейс), обе формы запуска (с `1cv8` и без),
status/stop, гашение после закрытия клиентов, уведомления из контейнера,
ТЖ пишет события.

Проверено: сценарий «конфигуратор → клиенты →
закрыл конфигуратор» на реальном окне; серверная база.

## TJ-01. Технологический журнал — ВЫПОЛНЕНО (2026-10-02)

- `volumes/logconf/logcfg.xml` — рабочий образец (точечные события
  EXCP/CONN/SCALL/SDBL); монтируется одиночным файлом в conf клиента
  (`/home/user/.1cv8/1C/1cv8/conf/logcfg.xml`) при наличии;
- ТЖ пишет в `volumes/techjournal/1cv8_<pid>/ГГММДДЧЧ.log`;
  монтирование в `/tmp/1c-techjournal` (вне home);
- проверено на файловой базе: события SDBL/EXCP/EXCPCNTX пишутся,
  владелец файлов — пользователь хоста;
- факт платформы 8.3.27.2342: `<all/>` не даёт событий (каталог
  создаётся, файл пуст) — в конфиге не использовать; инструкция в
  docs/run.md.
