## SCR-01. Скрипты жизненного цикла — ВЫПОЛНЕНО (переработано 2026-10-02)

- `client/entrypoint.sh`: первый аргумент — имя бинарника 1С
  (`1cv8c`/`1cv8`/`1cestart`), остальное — ключи; неизвестное слово = ключ
  `1cv8`; `LC_ALL=ru_RU.UTF-8`, `GTK_USE_PORTAL=1`; PID-1 ветка:
  trap SIGTERM, цикл `pgrep 1cv8` + `read -t 2`, `wait -n` реапит зомби;
  прогревочное GTK-окно удалено (не нужно на базе 24.04);
- `bin/1c-run.sh`: команды start/stop/status/build/build+test/build+start;
  exec при живом контейнере, run с `--rm` при отсутствии; тестовый образ
  собирается с тегом `-test`; session-dbus хоста монтируется.

Проверено агентом: холодный старт, файловая база (конфигуратор, толстый,
тонкий, русский интерфейс), status/stop, гашение после закрытия клиентов,
уведомления из контейнера (ADR-0008), тестовый образ (strace и др.).

Осталось (в приёмке): сценарий «конфигуратор → клиенты → закрыл
конфигуратор» на реальном окне, серверная база.
