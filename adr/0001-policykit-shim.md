# ~ADR-0001: policykit-1 shim при сборке образа (Ubuntu 26.04)~

**Статус:** не нужен (на базе ubuntu:24.04 `policykit-1` — реальный
пакет, установщик ставит его сам). Shim оставлен для истории; актуален
только при возврате на 26.04.

## Контекст

Компонент `v8_install_deps` дистрибутива 8.3.27.2342 делает
`apt-get install policykit-1`. В Ubuntu 26.04 этот пакет выпилен
(виртуальный, замена — `polkitd`), установка падает:
`E: Package 'policykit-1' has no installation candidate`.

## Решение

При сборке образа создаём локальный shim-пакет `policykit-1` (equivs,
версия 999) с `Depends: polkitd`, ставим его до запуска установщика.
Имя совпадает — установщик доволен, реальный функционал даёт polkitd.

## Почему так

- Пропатчить установщик 1С нельзя (самораспаковывающийся бинарник).
- Ставить реальный старый policykit-1 из 24.04 — тащить несовместимое.
- Shim — 4 строки, самодостаточен, удаляется вместе с прослойкой сборки.
