## [Unreleased]

### Очистка и переосмысление (2026-10-02)

Выявлено наслоение результатов тестов: проверки гонялись на несвежих
образах/контейнерах, выводы друг друга маскировали. Правило процесса:
одна гипотеза за раз, полная цепочка от build.

- База образа ubuntu:26.04 → ubuntu:24.04: устранено зависание
  «окна 1С создаются, но не мапятся» (ADR-0007). На 24.04 шим
  policykit-1 не нужен (ADR-0001), состав зависимостей платформы
  перенесён в Containerfile (`V8_PACKAGES`): v8_install_deps на 24.04
  не работает (список пакетов уходит в apt одним аргументом).
- Удалены костыли из-за зависания: прогревочное GTK-окно entrypoint,
  Breeze-тема + симлинки + копирование settings.ini (ADR-0006
  опровергнут), locale-зеркалирование хоста из 1c-run.sh.
- Удалён бандл libstdc++/libgcc_s из каталога версии (GLIBCXX_3.4.29+
  нужен webkit-бандлам); добавлены mscorefonts (EULA при сборке) —
  предупреждение 1С о шрифтах исчезло.
- Синтаксис запуска: `bin/1c-run.sh [команда] [аргументы…]` —
  start/stop/status/build/build+test/build+start; первый аргумент
  entrypoint — имя бинарника 1С (`1cv8c`/`1cv8`/`1cestart`), остальное —
  ключи 1С; неизвестное слово = аргумент `1cv8` (ADR-0004).
  Отладочные пакеты — только в MODE=test.
- Язык интерфейса: `LC_ALL=ru_RU.UTF-8` в entrypoint; локаль образа
  ru_RU.UTF-8; хост-локаль не зеркалится (ADR-0005 пересмотрен).
- Session-dbus хоста в контейнер: уведомления KDE работают; файловые
  диалоги остаются GTK (портал платформой не используется), ADR-0008.
- have_clients упрощён (`pgrep 1cv8`, зомби реапятся `wait -n`).
- tools/recon-run.sh удалён (разведка окончена), volumes/ целиком
  в .gitignore, docs/ актуализированы.
- `bin/1c-run.sh`: команда `help`; варианты сборки `build+test`
  (отладочные пакеты) и `build+breeze` (Breeze GTK-тема, без принудительной
  настройки GTK) — **тег один, используется последний собранный**;
  exec/run-пути больше не печатают хеш контейнера в stdout.
- docs/build.md: таблица библиотек справки 1С с фактическим состоянием
  в образе (ImageMagick и libgsf — бандлы платформы, системный
  ImageMagick не ставится — проверено, soname несовместим).
- Технологический журнал: `logcfg.xml` монтируется одиночным файлом в
  conf клиента (клиенты ищут его в `~/.1cv8/1C/1cv8/conf`, проверено
  strace); ТЖ пишет в `/tmp/1c-techjournal` (вне home); работают
  точечные события EXCP/CONN/SCALL/SDBL; инструкция и пример события в docs/run.md.
- Тома упрощены: `exchange/` и `client-profile/` удалены; home — единый
  персистентный том (профиль клиента, включая списки баз, живёт в нём);
  build+breeze прописывает `gtk-theme-name=Breeze` в
  `volumes/home/.config/gtk-3.0/settings.ini`, обычный build снимает.
- Пользователь контейнера переименован ubuntu → user (uid 1000 тот же,
  `usermod`; keep-id и права томов не меняются) — готовность к другим
  базовым дистрах.
- Исправлено: неизвестное первое слово (DESIGNER и пр.) в entrypoint
  съедалось — теперь передаётся первым аргументом `1cv8`; формы
  `1c-run.sh 1cv8 DESIGNER ...` и `1c-run.sh DESIGNER ...` эквивалентны.
- docs/integration.md: как podman/docker доставляет окна из контейнера
  на экран (X11-сокет, DISPLAY, xauth, XWayland); там же ответ про
  docker-переносимость схемы (без изменений, не проверено).

### История

- Скелет проекта: структура каталогов, AGENTS.md, план работ (ROADMAP).
- Разведка зависимостей 8.3.27.2342 на ubuntu:26.04 (run/recon/REPORT.md):
  v8_install_deps + shim policykit-1, подмена UI-бандлов на webkit-4.1
  варианты (.wk41), удаление бандлов libstdc++/libgcc_s; факт: клиенты
  работают без LD_LIBRARY_PATH (ADR-0001..0003).
- Образ клиента `localhost/1c-client:8.3.27.2342` (client/Containerfile,
  client/entrypoint.sh).
- Скрипты жизненного цикла: bin/1c-run.sh (run/exec), точка входа с
  SIGTERM и подсчётом клиентов; podman stop ~0.1 c.
- Документация: docs/build.md, docs/run.md, docs/acceptance.md.
- Исправление: в образ добавлен libunwind8 — без него 1cestart и
  толстый клиент падают молча (симптом «окно конфигуратора не
  появляется»); в entrypoint добавлен тип `cestart` (штатный лаунчер
  1cestart), ADR-0004.
- Локаль контейнера берётся с хоста при старте (LANG + LC_* категории
  по факту `locale` хоста, невыставленные — очищаются).
- Тома: отдельный `volumes/home` на весь /home/ubuntu и отдельный
  `/exchange`; home отключаемо одной правкой.
- Файловые диалоги GTK в стиле KDE: breeze-gtk-theme в образе +
  прокидывание хостовых настроек темы в контейнер (без dbus/порталов).
- entrypoint: опрос заменён с `sleep`-процесса на встроенный
  `read -t 0.5` (лишние процессы в /proc не торчат).
- Язык интерфейса 1С: процессы 1С запускаются с
  `LC_MESSAGES=ru_RU.UTF-8` (точечно, только для 1С; остальные
  категории локали — хостовые), ADR-0005.
- Breeze-тема для GTK-диалогов: breeze-gtk-theme в образе + симлинки
  темы в ~/.local/share/themes; ловушка «settings.ini без темы = окна
  не мапятся», ADR-0006.
