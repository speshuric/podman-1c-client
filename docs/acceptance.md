# Приёмка: сценарий проверки

Прогон по критериям TASK.md. Агент проверяет то, что возможно без
лицензии/сервера; остальное — пользователь руками (колонка «Кто»).

Команды — в новом синтаксисе (docs/run.md): первый аргумент после
`start` — бинарник 1С, остальное — ключи.

| # | Критерий | Как проверить | Кто | Результат |
|---|---|---|---|---|
| 1 | Запускаются конфигуратор, тонкий, толстый, обычное приложение, подключаются к серверу, открывают базу | Для каждого: `bin/1c-run.sh start 1cv8c /S сервер\база /N … /P …` (тонкий), `start 1cv8 ENTERPRISE …` (толстый/обычное), `start 1cv8 DESIGNER …` (конфигуратор) — окно открылось, база открыта, интерфейс русский | пользователь | файловая база: все три открыты, русский; серверная база: проверено пользователем |
| 2 | Сохраняется community лицензия | Положить лицензию в `volumes/licenses/`, запустить клиент, выйти; лицензия осталась и подхватывается при следующем запуске | пользователь | — |
| 3 | Работают элементы на встроенном браузере (HTML-поле) | Открыть базу с формой с HTML-полем | пользователь | проверено пользователем |
| 4 | Русская раскладка и буфер обмена в обе стороны | Набрать русский текст в 1С и в KDE-приложении, копировать туда-обратно | пользователь | проверено пользователем |
| 5 | Файлы от клиента принадлежат пользователю хоста | Сохранить файл через диалог 1С в домашний каталог, проверить владельца на хосте: `ls -lan volumes/home/` | пользователь | — |
| 6 | Файлы ТЖ остаются и принадлежат пользователю хоста | Включить ТЖ (logconf), поработать, закрыть клиент, `ls -lan volumes/techjournal/` | пользователь | ТЖ пишет события (агент: EXCP/SDBL/CONN/SCALL) |
| 7 | «Конфигуратор → запустил клиентов → закрыл конфигуратор» — клиенты живут, контейнер гаснет после последнего | Запустить конфигуратор, из него тонкий и толстый, закрыть конфигуратор: клиенты живы; закрыть клиентов → `bin/1c-run.sh status` — not running | пользователь | проверено пользователем |
| 8 | Второй запуск при живом контейнере поднимает ещё окно | `bin/1c-run.sh` дважды — два окна | пользователь | — |
| 9 | Сборка другой версии сменой одного аргумента | `PLATFORM_VERSION=8.5.1.1522 bin/1c-run.sh build` | пользователь/агент | проверено агентом: чистая сборка 8.5.1.1522, ldd чист, запуск ok (2026-10-02) |
| 10 | `podman stop` быстро, без таймаута | при живом клиенте `time podman stop 1c-client-8.3.27.2342` — доли секунды | агент: 0.1 с | — |
| 11 | Уведомления из 1С доходят до хоста | Отправить из контейнера `org.freedesktop.Notifications.Notify` (ADR-0008); KDE-тост появился | агент: да | — |

Проверено агентом до приёмки (свежая цепочка build → start):

- [x] `ldd` всех четырёх бинарников (1cv8, 1cv8c, 1cv8s, 1cestart)
      чистый; шрифты mscorefonts на месте (предупреждение 1С исчезло);
- [x] холодный старт `bin/1c-run.sh`: стартовый диалог мапится, русский;
- [x] конфигуратор / толстый / тонкий на файловой базе открываются,
      интерфейс русский;
- [x] `status`/`stop`; контейнер гаснет после закрытия клиентов,
      `--rm` убирает его;
- [x] session-dbus: уведомления хоста из контейнера (ADR-0008);
      файловые диалоги 1С — GTK-вид (портал платформа не использует);
- [x] ТЖ пишет события (EXCP, EXCPCNTX, SDBL; конфиг с точечными
      `<event>`; `<all/>` не работает — см. docs/run.md);
- [ ] сборка 8.5.1.1522 (нет в списке приоритетов заказчика, при
      необходимости — командой из docs/build.md).
